# The Pig Game
Pig Game is a simple two-player dice game where players take turns rolling a dice, accumulating points, and aiming to reach a set score. This project was developed as part of *The Complete JavaScript Course* by Jonas Schmedtmann.

## Game Rules

- Two players take turns rolling a dice.
- On each turn, a player can roll the dice as many times as they like. The rolled number is added to their round score.
- If the player rolls a 1, their current round score is lost, and it's the next player's turn.
- Players can choose to "Hold" to save their round score and add it to their total score.
- The first player to reach 100 points wins the game.

## Features

- Two-player mode with turn-based gameplay
- Roll dice and hold functionality
- Reset game option
- Displays current scores, round scores, and winner

## Technologies Used

- Vanilla JavaScript (ES6)
- HTML & CSS

## Running the Application
1. Clone the repository
